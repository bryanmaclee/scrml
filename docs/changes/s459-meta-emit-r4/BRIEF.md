- **F1 (MED) — emitted markup acting on the page by reference.** Governing: §22.12 *Attributes* refuses `popovertarget`/`commandfor`/`command`/`anchor` because "they act on another element of the page by id", and `form=` because "data must not … retarget a submission". (a) REFUSE `for` on `<label>` (keep `<output for>`): `meta.emit('<label for="danger">')` + click ran the page's `#danger` handler (pwn 99); with `style="position:fixed;inset:0;…;opacity:0"` every page click became a click on `#danger` (pwn 98). (b) Form-control injection: when the INSERTION POINT has an ancestor `<form>` (checked through the captured accessors at insert time), refuse form-associated controls in the emitted tree (`input`, `button`, `select`, `textarea`, `output`, `fieldset`, `object`, form-associated custom elements) — an injected `<input type=hidden name=amount value=999999>` fed `new FormData(pf)` and `<button type=submit>` submitted the page form. Same refusal path (nothing written, one log). (c) `style`: do NOT build a CSS parser; document the overlay/clickjacking residual in the §22.12 "Not a sandbox" note.
- **F2 (MED) — the runtime-only id/name belt over-refuses** (`<input name="name">`, `<h2 id="title">`, `id="hidden"`, 375 names in HTMLFormElement.prototype, on every element). Scope it to elements that create NAMED PROPERTIES on `document`/`window` or a form: form-associated controls (name), `form`, `img`, `embed`, `object`, `iframe` (name and id per the HTML spec's named-property rules) — refuse a name/id there that is `in` the relevant captured prototype (HTMLFormElement / Document / Window as applicable). Plain elements (`div`, `h2`, `section`, `p`…) are admitted with any id/name. Keep the `^_{1,2}scrml` id/name refusal in both phases. Apply the SAME rule at compile time (meta-eval checkEmittedNodes) so the phases agree; measure corpus impact.
- **F3 (LOW)** `<svg><template>` / `<math><template>` → uncaught `TypeError: Illegal invocation` from the HTMLTemplateElement `content` getter (`compiler/src/runtime-meta-emit-gate.js` ~:176). Guard on the HTML namespace; a non-HTML `template` is walked as an ordinary element; report via the logging surface, never throw.
- **F4 (LOW) — one judge for URL values in both phases.** Compile-time `emit()` admits `<a href="javascript:…">`, `" javascript:"`, `java\nscript:`, `xlink:href`, MathML `href`, `poster`, `srcset` candidates; the runtime refuses them. - **F5 (LOW)** `<meta name>` lowercase-token rule refuses `Description`, `DC.title`, `msapplication-TileColor` (meta names are ASCII case-insensitive; `<meta name>` creates no named property, so the rule does no clobbering work).
