# structure.map.md
# project: scrml
# updated: 2026-07-26T07:00:00Z  commit: f8a138e9

## Entry Points
compiler/bin/scrml.js — CLI shim; resolves to compiler/src/cli.js.
compiler/src/cli.js — dispatches `scrml compile|dev|build|serve|migrate|db-migrate|promote|generate|init|introspect|semdiff` (11 verbs, `db-migrate` NEW S287) to compiler/src/commands/*.js.
compiler/src/api.js — `compileScrml()`, the single-file pipeline entrypoint (block-split -> AST-build -> type-check -> codegen); everything else calls into this. Carries the `moduleFormat` option (default `"classic"`) and the esm-gated build-path import-URL hasher (`rewriteChunkImportRefs`).
lsp/server.js — LSP server entry (`bun run lsp` / `--stdio`); registers handlers.js + workspace.js.
docs/build.ts — static-site generator for the docs website (`bun run docs:build`).

## Directory Ownership

compiler/src/  — the compiler core: block-splitter, tokenizer, ast-builder, type-system, symbol-table, route-inference, name-resolver, html-elements, compute-program-config, landmark-tag, tag-canonicalizer, schema-differ, and ~20 top-level analysis modules. **187 tracked files (143 .ts + 42 .js + 2 other)**, `git ls-files`-counted this pass. Net **+3** across this window (`1c5c2aee` -> `f8a138e9`), all additions, no deletions: **+3 NEW** (`commands/db-migrate.js`, `codegen/db-authoritative.ts`, `codegen/sql-ident.ts` — the §14.8.11 DB-authoritative tier, S287). `schema-differ.js` (pre-existing, not counted as new) was heavily extended in place.
compiler/src/codegen/  — code emission: one emit-*.ts per output concern plus shared collect/rewrite/reactive-deps/errors infra. **85 files (81 .ts + 3 .js + 1 .md)**, **+2 this window** (`db-authoritative.ts`, `sql-ident.ts`).
compiler/src/commands/  — **12 files**, **+1 this window** (`db-migrate.js`). See "the `scrml db-migrate` command" below.
compiler/src/schema-differ.js  — **HEAVILY EXTENDED this window (§14.8.11/.1/.2, S287).** Was the §38.6 SQLite-only migration-SQL differ (desired `<schema>` AST vs actual `PRAGMA table_info()`). Now ALSO: a brace-depth-aware `parseSchemaBlock` (hand scanner, not the old non-nested `/(\w+)\s*\{([^}]*)\}/g` regex — a P2 `fn`'s `"""…"""`-quoted plpgsql body itself contains braces, which the old regex would truncate at) returning `{tables, fns}` (the `fns` array is ADDITIVE, empty for a schema with no `fn`); `parseColumns`'s per-column `immutable` bareword keyword (mirrors `not null`/`unique`); `generateDbAuthoritativeDDL(table)` — S1 RLS+policy + S6 bounded-role GRANT, RE-SHAPED to column-scoped (`GRANT UPDATE (<mutable cols>)`) when any column is `immutable` (byte-identical to the M1 shape when zero columns are `immutable` — anti-regression, normative); `generateScrmlHasCapDDL()` + `generateSecdefDDL(fn, dbAuthTables)` — the S4 SECURITY-DEFINER mutation-choke emitter (hardened: `SET search_path = pg_catalog, public`, bounded NOLOGIN owner role distinct from `scrml_app`, `REVOKE EXECUTE FROM PUBLIC`); the `allowDestructive` fence in `diffSchema` (default false — a bare `DROP TABLE` for an actual-but-not-desired table is suppressed with `W-SCHEMA-DESTRUCTIVE-DROP`, since a Postgres DROP CASCADEs the attached RLS policy/grants). Exports `DBAUTH_ROLE`/`DBAUTH_POLICY`/`DBAUTH_TENANT_GUC`/`DBAUTH_CAPS_GUC` (the shared constant names). See dependencies.map.md, schema.map.md, migrations.map.md.
compiler/src/codegen/db-authoritative.ts  — **NEW (§14.8.11 M1/P2, S287).** `appDeclaresDbAuthoritative(fileAST)` — the conditional-engagement gate (an app with zero `db-authoritative` tables emits byte-identically to before). `wrapPrincipalTxn(src)` — the A1/S2 per-request-principal codegen transform: a SCOPE-AWARE rewrite (tracks a brace-scope stack of `_scrml_req`-in-scope flags, not a name-blacklist) that wraps a genuine `_scrml_sql`/`_scrml_sql_<n>` query site into `.begin(async (tx) => { pin scrml.tenant + scrml.principal.caps via set_config; SET LOCAL ROLE scrml_app; return await …the original query…on tx })`, but ONLY inside a function scope where `_scrml_req` is bound — so a module-level infra helper (e.g. `_scrml_idempotency_ensure_table`, which takes no `_scrml_req`) is never wrongly wrapped. `extractDesiredSchema(fileAST)` — the migration-apply desired-state seam: walks every `<schema>` block, merges tables+fns across the file (first-decl wins), and detects a `db-authoritative`-like near-miss token (`W-DBAUTH-MARKER-NEARMISS`). Imported by `codegen/index.ts` (wired into `emit-server.ts`'s `generateServerJs`, :4663-4672) and `commands/db-migrate.js`.
compiler/src/codegen/sql-ident.ts  — **NEW (§14.8.11.1, S287).** `quoteIdent(name)` — the sole safe SQL-identifier escaper (doubles an embedded `"`: `a"b` -> `"a""b"`). SECURITY-CRITICAL: `readActualSchemaPg`/`readActualSchema` read table/column names from the LIVE database (an attacker who can influence the schema controls them), and `scrml db-migrate` runs the resulting SQL as the MIGRATOR (the most-privileged principal) — an unescaped identifier is a direct SQL-injection path to a permissive-RLS-policy install or `ALTER ROLE … SUPERUSER`. Imported by `schema-differ.js` and `codegen/emit-channel.ts` (aliased `pgQuoteIdent`).
compiler/src/commands/db-migrate.js  — **NEW (§14.8.11.1, the `scrml db-migrate` command, S287).** `runDbMigrate(args)` — parses `--db <url>` (REQUIRED, the MIGRATOR/owner connection, a DIFFERENT more-privileged principal than the app runtime's `db=`), `--dry-run`, `--allow-destructive`; parses the project's `<schema>` via the live parse pipeline + `extractDesiredSchema`; pre-flights `E-DBAUTH-SQLITE` (non-Postgres target with a db-authoritative table or SECDEF fn) and `E-DBAUTH-NO-TENANT-COLUMN`; applies via `runPgApply` (Postgres: `pg_advisory_xact_lock` -> ensure the thin `_scrml_migrations` ledger -> `readActualSchemaPg` + a narrow `pg_policies`/`pg_roles` presence read -> `diffSchema({driver:"postgres"})` -> apply each statement in ONE transaction, recording `{object_kind, object_name, ddl_hash}` per statement via `classifyStatement`) or `runSqliteApply` (a general, roles-free `<schema>`-apply for SQLite, Fork 5). PRIVILEGE SEPARATION is load-bearing: the emitted app connects as the bounded `scrml_app` role (`SET LOCAL ROLE`, NOLOGIN NOBYPASSRLS) and can never apply/alter the security DDL itself — auto-apply-on-boot is eliminated for Postgres BY DESIGN. `parseArgs`/`classifyStatement` exported for unit tests. See migrations.map.md.
compiler/src/codegen/runtime-esm.ts  — Transforms the assembled POST-SLICE classic runtime string into a valid ES module for `--module-format=esm`. Exports `toEsmRuntime`, `deriveTopLevelExportNames`, `LIFT_TARGET_GLOBAL`, `REACTIVE_GET_OVERRIDE_SLOT`.
compiler/src/codegen/emit-client-esm.ts  — Transforms a per-file classic client chunk body into an ES module. Export `toEsmClientChunk`.
compiler/src/commands/module-format-notice.js  — `moduleFormatNotices(moduleFormat, embedRuntime)` — the stderr operational notice for `--module-format=esm`, keyed `W-MODULE-FORMAT-ESM-INCOMPLETE`. NOT a §34 catalog code and never in the diagnostic stream; returns `[]` for classic. Imported by commands/{compile,dev,build}.js.
compiler/src/codegen/index.ts  — the codegen dispatcher (= code-generator.js). Owns the chunk-namespace WIRING (`CELL_SCOPE_ACCESSORS`, `buildCellScopePrologue`, `addCellScopePrologue`, `wrapChunkBodyInIife`), the §40.8.2 multi-file shell composition, AND (S287) the `E-DBAUTH-SQLITE` compile-time driver-resolution gate (`annotateDbScopes`) plus the `appDeclaresDbAuthoritative`/`wrapPrincipalTxn` call sites feeding `emit-server.ts`.
compiler/src/codegen/emit-each.ts  — `<each>` emission. `emitEachMountHtml` emits the NAMESPACED parse-safe comment FENCE `<!--scrml-each:${nsId(N)}--><!--/scrml-each:${nsId(N)}-->` (never foster-parented out of a `<table>` nor dropped by "in select"). Per-item `bind:*` value-side wiring for OUTER/shared reactive cells inside `<each>` (i175); a per-item `bind:*` writing to an ITERATION-ITEM field instead now fires `W-EACH-BIND-ITEM-FIELD-DEFERRED` (write-back not yet lowered) rather than silently dropping.
compiler/src/runtime-template.js  — the client runtime shipped into generated apps: soft-nav engine, link-boost delegated click listener, the `[data-scrml-outlet]` swap target, and the range-aware list reconciler (`_scrml_reconcile_list`, `_scrml_find_each_anchor`, `_scrml_each_clear`/`_scrml_each_append`/`_scrml_remount_each`). Namespace-aware (splits an already-namespaced `<token>$` varKey prefix back for slot addressing).
compiler/src/tag-canonicalizer.ts  — Stage 3.055 TC. A capitalized tag (`<Button>`) EMITS what the §15.X registry resolved it to. Imported by `landmark-tag.ts` + `api.js`.
compiler/src/landmark-tag.ts  — a single-export module: `isAuthorMainTag(node)`, the ONE `<main>` landmark predicate, imported by BOTH `symbol-table.ts`'s `collectOutlets` (SYM PASS 15.5) and `codegen/emit-html.ts`'s `treeHasAuthorMain`.
compiler/src/symbol-table.ts  — the SYM pass battery. PASS 15.5 `collectOutlets` walks TOTALLY, mirroring its emit twin `treeHasAuthorMain`, and resets `inRouteScope` at a nested `<program>` boundary (§4.12.1). PASS 5a `walkNonBindableMarkupDecls` owns the DECL-scoped `E-CELL-RENDER-SPEC-NOT-BINDABLE`.
compiler/src/types/  — shared TS type declarations: ast.ts (the FileAST/ASTNode catalog, carries `ReturnStmtNode.fnExprNode`), auth-graph.ts, reachability.ts. **No `<outlet>` node type, no each-mount node type, and no DB-authoritative node type exist here** — `<outlet>` is a plain `kind: "markup"` node, the each mount is an emitted string, `ChunkNamespaceState` is codegen-internal, and `TableDecl`/`SecdefFnDecl` (the schema-differ.js return shapes) are codegen-internal too, not AST shapes.
