# structure.map.md
# project: scrml
# updated: 2026-07-25T16:00:00Z  commit: 1c5c2aee

## Entry Points
compiler/bin/scrml.js — CLI shim; resolves to compiler/src/cli.js.
compiler/src/cli.js — dispatches `scrml compile|dev|build|serve|migrate|promote|generate|init|introspect|semdiff` to compiler/src/commands/*.js.
compiler/src/api.js — `compileScrml()`, the single-file pipeline entrypoint (block-split -> AST-build -> type-check -> codegen); everything else calls into this. Carries the `moduleFormat` option (default `"classic"`, api.js:822) and the esm-gated build-path import-URL hasher (`rewriteChunkImportRefs`, ~:2947-3010).
lsp/server.js — LSP server entry (`bun run lsp` / `--stdio`); registers handlers.js + workspace.js.
docs/build.ts — static-site generator for the docs website (`bun run docs:build`).

## Directory Ownership

compiler/src/  — the compiler core: block-splitter, tokenizer, ast-builder, type-system, symbol-table, route-inference, name-resolver, html-elements, compute-program-config, landmark-tag, tag-canonicalizer, and ~20 top-level analysis modules. **184 tracked files (141 .ts + 41 .js + 1 .md + 1 .json)**, `git ls-files`-counted this pass. Net **+3** across this window (`a0344d75` -> `1c5c2aee`), all additions, no deletions: **+3 NEW** (`codegen/cell-accessor-rename.ts`, `codegen/chunk-namespace.ts`, `tag-canonicalizer.ts`).
compiler/src/codegen/  — code emission: one emit-*.ts per output concern plus shared collect/rewrite/reactive-deps/errors infra. **83 files (79 .ts + 3 .js + 1 .md)**, **+2 this window** (`cell-accessor-rename.ts`, `chunk-namespace.ts` — the chunk-namespacing BUG-6 machinery).
compiler/src/codegen/chunk-namespace.ts  — **NEW (chunk-namespacing BUG-6, #180).** The per-compilation-unit namespace for the runtime-global tokens a chunk emits — so two route chunks in one live document no longer clobber each other's id / cell-key / engine-name / mount-attribute space (N1-N4). Owns the module-level namespace STATE (`setChunkNamespaceState`/`resetChunkNamespaceState`/`currentChunkNamespace`) and the token machinery: `resolveProjectRoot` (:108, walks up for `scrml.toml` / `.git`, memoized; falls back to the FILESYSTEM ROOT when neither exists — a DEVIATION from the S282 hard-error ruling, flagged for ratification, but strictly MORE injective than a project-relative path), `chunkNamespaceToken` (:162, `fnv1aHash` of the project-relative path), `nsId` (:242, `24`->`"0a1b2c3d_24"`), `nsName` (:259, DOM markers), `nsCellKey` (:383, store keys `"rows"`->`"0a1b2c3d$rows"`), `stripNsName` (:402, inverse of `nsName`), `buildCellOwnerMap` (:292, cross-file imported cells key under the EXPORTER's token per §51.0), and `assertChunkTokensDistinct` (:182, D2 — a token collision is a HARD error, explicitly NOT the `E-CG-010` catalog code). Every helper returns the BARE value when no namespace is installed, so synthetic unit tests see today's output.
compiler/src/codegen/cell-accessor-rename.ts  — **NEW (chunk-namespacing BUG-6, #180).** `renameCellAccessors` (:78) — an Acorn-parse + range-SPLICE bundle-assembly pass that rewrites every cell-accessor CALL in the assembled chunk BODY from the bare runtime name to its chunk-local `_scrml_cs_` wrapper (`_scrml_reactive_get("rows")` -> `_scrml_cs_reactive_get("rows")`). Only the callee identifier moves; the `"rows"` store-key argument stays byte-identical (~1200 tests pin the bare key). PARSES rather than regex-matches (a comment / string-literal that merely contains the accessor text is not a call) and SPLICES rather than regenerates (a round-trip would reflow every line + destroy the readability comments). Runs on the BODY ONLY, before the prologue is prepended — the ordering that lets the wrappers delegate to the real accessors without renaming those. `CS_PREFIX = "_scrml_cs_"` (:48). Returns `used` (the exact accessor set the prologue must wrap) + `valueReferences` (an accessor passed as a value not a callee — zero on the corpus today, tracked so a future callback-passing emitter is caught not leaked). NO emitter emits `_scrml_cs_` directly — this pass is the SOLE producer.
compiler/src/codegen/fnv1a-hash.ts  — the shared FNV-1a 32-bit -> 8-char base36 hash primitive (§47.1.3 normative). **This window: docstring gained the THIRD call-site class** — the chunk-NAMESPACE token (`chunk-namespace.ts`), the only site that ENFORCES token distinctness (the other two — §47.1.2 per-binding type-encoding and §47.5 per-chunk content-address — do not). Every token starts with `0`; shape-match `0[0-9a-z]{7}`.
compiler/src/codegen/runtime-esm.ts  — **(ESM-chunks U1, prior window.)** Transforms the assembled POST-SLICE classic runtime string into a valid ES module for `--module-format=esm`. Exports `toEsmRuntime` (:304), `deriveTopLevelExportNames` (:256, Acorn-derived export surface), `LIFT_TARGET_GLOBAL` (:71), `REACTIVE_GET_OVERRIDE_SLOT`. Three esm-gated transforms: `^{}` dep-tracking via `globalThis.__scrml_reactive_get_override`; redeclare-guard simplification; the trailing `export { … }` block.
compiler/src/codegen/emit-client-esm.ts  — **(ESM-chunks U2, prior window.)** Transforms a per-file classic client chunk body (post runtime-slice-strip, PRE the cross-file IIFE wrap) into an ES module. Export `toEsmClientChunk` (:270). `_scrml_modules["<key>"] = {…}` footer -> `export {…}`; the destructure header -> a NAMESPACE import; a runtime import of `(runtime exports ∩ chunk idents) − own decls`. `SHARED_MUTABLE_RUNTIME_GLOBALS` (:73) route through `globalThis.<name>` (an imported ESM binding is read-only).
compiler/src/commands/module-format-notice.js  — `moduleFormatNotices(moduleFormat, embedRuntime)` — the stderr operational notice for `--module-format=esm`, keyed `W-MODULE-FORMAT-ESM-INCOMPLETE`. NOT a §34 catalog code and never in the diagnostic stream; returns `[]` for classic. Imported by commands/{compile,dev,build}.js.
compiler/src/codegen/index.ts  — the codegen dispatcher (= code-generator.js). **This window: owns the chunk-namespace WIRING.** `CELL_SCOPE_ACCESSORS` (:474, the accessor set the rename pass + prologue share), `cellScopeKeyFn` (:560) / `buildCellScopePrologue` (:598, DEFINES the `_scrml_cs_*` wrappers), `addCellScopePrologue` (:638, calls `renameCellAccessors` at :667 then prepends the prologue), `wrapChunkBodyInIife` (:683, NEW #180 — wraps the classic client chunk body in an IIFE so top-level `const`/`function` are chunk-local; `import`/`export`/`_scrml_modules[...]=` hoisted OUTSIDE; gated `moduleFormat !== "esm"`, skipped under `--embed-runtime`). Per-file loop: :1243 `resolveProjectRoot`, :1252 `assertChunkTokensDistinct`, :1290/:1573 `setChunkNamespaceState`, :1969 `buildCellOwnerMap`, :1971 `chunkNamespaceToken`, :1973 `addCellScopePrologue`, :2019 `wrapChunkBodyInIife`, :2324 `resetChunkNamespaceState`. Also the §40.8.2 multi-file shell composition (see dependencies.map.md).
compiler/src/codegen/emit-each.ts  — `<each>` emission. `emitEachMountHtml` (:385) emits the **NAMESPACED parse-safe comment FENCE** `<!--scrml-each:${nsId(N)}--><!--/scrml-each:${nsId(N)}-->` (a comment is inserted in EVERY HTML insertion mode, so it is never foster-parented out of a `<table>` nor dropped by "in select"; the two-comment form bounds the keyed-reconcile range). Render-fn names / renderer-registry keys / match-dispatch ids all pass through `nsId` (multi-chunk safe). **This window (Peter #175, i175): per-item `bind:*` value-side wiring for OUTER/shared reactive cells inside `<each>`** — :1539 the value-side branch, :1997 the file-scoped-inputs publish; suppressed when a `bind:value` binding is present (:614). Reconcile emit calls the polymorphic runtime ops `_scrml_each_clear`/`_scrml_each_append` and locates the mount via `_scrml_find_each_anchor` — never `querySelector`. A NESTED each still builds its mount with `createElement` + `setAttribute("data-scrml-each-mount", "each_${nsId(N)}")` (:1095) — immune to parse-time foster-parenting but a separate open gap in restricted parents.
compiler/src/runtime-template.js  — the client runtime shipped into generated apps: soft-nav engine, link-boost delegated click listener, the `[data-scrml-outlet]` swap target (`querySelector` at ~:2238/:2436), and the **range-aware list reconciler**: `_scrml_reconcile_list` (:1652) branches on `container.nodeType === 8` (comment anchor -> fence sibling range via `_scrml_each_end`) versus an element container; `_scrml_each_end` (:1963), `_scrml_find_each_anchor` (:1989, memoized SHOW_COMMENT TreeWalker mirroring `_scrml_find_if_marker` :1381), `_scrml_each_clear` (:2006), `_scrml_each_append` (:2019), `_scrml_remount_each` (:2131). **This window: the accessor path learned chunk namespacing** — a varKey may arrive ALREADY namespaced (`"0abc$playMode"`) and the runtime splits the `<token>$` prefix back for slot addressing; the chunk-local `keyFn` is null for an unscoped (no-namespace) call.
compiler/src/tag-canonicalizer.ts  — **NEW this window (Stage 3.055 TC, #155).** A capitalized tag (`<Button>`) EMITS what the §15.X registry resolved it to — §4.2/§4.3 casing-irrelevant resolution (NR already stamps `<Button>` as `html-builtin`). Imported by `landmark-tag.ts` + `api.js` (wired as pipeline Stage 3.055).
compiler/src/landmark-tag.ts  — a single-export module: `isAuthorMainTag(node)`, the ONE `<main>` landmark predicate, imported by BOTH `symbol-table.ts`'s `collectOutlets` (SYM PASS 15.5) and `codegen/emit-html.ts`'s `treeHasAuthorMain`. Case-INSENSITIVE but guarded by NAME RESOLUTION (`isUserComponentMarkup`). Touch landmark logic HERE, not in either walker.
compiler/src/symbol-table.ts  — the SYM pass battery. PASS 15.5 `collectOutlets` walks TOTALLY, mirroring its emit twin `treeHasAuthorMain`, and resets `inRouteScope` at a nested `<program>` boundary (§4.12.1). PASS 5a `walkNonBindableMarkupDecls` (:2892) owns the DECL-scoped `E-CELL-RENDER-SPEC-NOT-BINDABLE`.
compiler/src/commands/  — the 10 CLI subcommands (build, compile, dev, generate, init, introspect, migrate, promote, semdiff, serve) + module-format-notice.js. No new subcommand this window; `compile`/`dev`/`build` carry the `--module-format` flag parser.
compiler/src/types/  — shared TS type declarations: ast.ts (the FileAST/ASTNode catalog, carries `ReturnStmtNode.fnExprNode`), auth-graph.ts, reachability.ts. **No `<outlet>` node type and no each-mount node type exist here** — `<outlet>` is a plain `kind: "markup"` node, the each mount is an emitted string, and `ChunkNamespaceState` (chunk-namespace.ts) is a codegen-internal interface, not an AST shape.
compiler/src/validators/  — standalone AST-walk validators (attribute allowlist/interpolation, async-user-source lint, try-catch lint, post-CE invariant checks) — 6 files.
compiler/src/native-parser-canary/  — the within-node-classifier that diffs native-parser output against the live pipeline for parity tracking.
compiler/src/native-walker/  — 3 walkers (attrvalue-exprnode, engine-statechild, exprtext-backfill) used by the native-parser canary.
compiler/src/reachability/  — the reachability-solver's component/gate-classifier/fixpoint machinery (8 files).
compiler/native-parser/  — the from-scratch native lexer/parser (Road-B, Charter B): each stage ships as a paired `.js` (compiled/live) + `.scrml` (canonical source) — lex, parse-expr, parse-stmt, parse-markup, parse-file, translate-expr/stmt, error-recovery (79 files total). Feeds lsp/handlers.js semantic tokens. **ZERO diff since `df2ac831`, re-verified at THIS HEAD `1c5c2aee`** (`git diff --name-only df2ac831..HEAD -- compiler/native-parser/` returns 0 files). It is a lexer/parser/AST layer only — the chunk-namespace machinery is emit-time and carries NO native-parser parity obligation. `E-SCRIPT-001` IS in its layer and IS a confirmed gap (`parse-markup.js:983-995`). See non-compliance.report.md.
