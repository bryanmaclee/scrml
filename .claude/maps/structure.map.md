# structure.map.md
# project: scrml
# updated: 2026-07-28T16:35:00Z  commit: 115e8b1b

## Entry Points
compiler/bin/scrml.js — CLI shim; resolves to compiler/src/cli.js.
compiler/src/cli.js — dispatches `scrml compile|dev|build|serve|migrate|db-migrate|promote|generate|init|introspect|semdiff` (11 verbs) to compiler/src/commands/*.js.
compiler/src/api.js — `compileScrml()`, the single-file pipeline entrypoint (block-split -> AST-build -> type-check -> codegen); everything else calls into this. Carries the `moduleFormat` option (default `"classic"`), the esm-gated build-path import-URL hasher (`rewriteChunkImportRefs`), and (D-4, S296) the **dist-keyed forward index + `serverImportTargetSource`** that both cross-file server-import consumers reverse through.
lsp/server.js — LSP server entry (`bun run lsp` / `--stdio`); registers handlers.js + workspace.js.
docs/build.ts — static-site generator for the docs website (`bun run docs:build`).

Every other change this window is an in-place edit.
compiler/src/codegen/  — code emission: one emit-*.ts per output concern plus shared collect/rewrite/reactive-deps/errors infra. **85 files (81 .ts + 3 .js + 1 .md)**, unchanged in COUNT this window; heavily edited in place (`emit-server.ts` +231, `emit-lift.js` +193, `emit-each.ts` +125, `index.ts` +106, `emit-client.ts` +45, `scheduling.ts` +283, `emit-reactive-wiring.ts` +41, `emit-variant-guard.ts` +36, `emit-event-wiring.ts` +28, `emit-html.ts` +20, `binding-registry.ts` +13).
compiler/src/commands/  — **12 files**, unchanged in count. `db-migrate.js` gained scanner wiring + a widened `runPgApply` signature this window (see below).
compiler/src/sql-table-refs.js  — **NEW this window (S292, §14.8.11, closes `g-dbauth-migrate-no-grants-for-unmarked-identity-table`).** A bounded IDENTIFIER SCANNER over `?{}` SQL bodies — **explicitly NOT a SQL parser** (scrml carries none). Exports `tableRefsInSql(sql)`, `sqlBodiesInSource(source)`, `tableRefsInSource(source)`; each returns `{tables, privileges, undetermined}`. `TABLE_INTRODUCERS` pairs each clause with the PRIVILEGE its reference implies (`from`/`join`→SELECT, `insert into`→INSERT, `update`→UPDATE, `delete from`→DELETE; `PRIV_RANK` resolves the `DELETE FROM` double-match). `UNRESOLVABLE` enumerates the five shapes it deliberately does NOT resolve (CTE `WITH…AS(`, subquery in `FROM`/`JOIN`, `LATERAL`, dynamic `EXECUTE`) — those land in `undetermined`, which the caller REPORTS. **The two-valued contract is load-bearing: an empty `tables` must never be read as "touches nothing" — under-granting fails closed at runtime as an opaque `permission denied`.** Consumed by `commands/db-migrate.js`. Test: `compiler/tests/unit/sql-table-refs.test.js`.
compiler/src/codegen/scheduling.ts  — **NOT a new file** (it dates to the initial split) but **+283 lines this window**, all in one hunk, GH #237 (§13.2 + §6.7.1a). Eight NEW exports/helpers, none of which existed at `c700c435`: `scanEmittedCode` (a string/comment/template-literal-aware scan of ALREADY-EMITTED JS returning depth-0 statement ends + depth-0 brace-group spans), `precedesBlockBrace` (block-vs-object-literal `{` disambiguation), `continuesEmittedStatement` (`} else {` / `} catch {` / `} while (…)` continuation), `splitEmittedStatements`, `liftEmittedStatementAwaits` (+ `liftOneEmittedStatement`, `recurseEmittedBraceGroups`), and `emittedCodeCallsServerFn`. Sole consumer: `codegen/emit-reactive-wiring.ts:536-537` (the `on mount` async-scope wrap). Pre-existing exports (`buildCalleeImportMap`, `extractCalleeNames`, `hasServerCallees`, `injectPromiseAwait`, `scheduleStatements`, …) are untouched.
compiler/src/codegen/emit-client.ts  — **the runtime-chunk gate owner.** `detectRuntimeChunks(fileAST, ctx)` (:273) is the PRE-EMIT AST walk that registers every needed runtime chunk; `POST_EMIT_HELPER_CHUNK_GATES` (:2167) is the POST-EMIT reference scan for helpers no AST walk can see. **Neither lives in `codegen/index.ts`** — a routing blind spot that produced a wrong fix-locus in the GH #234 brief and is now corrected in primary.map.md's Task-Shape Routing. This window: the `messages` chunk gained a `["_scrml_message_for", "messages"]` POST-EMIT entry (GH #234 — `<errors of=…/>` captures the helper as a VALUE behind a `typeof` guard, so a call-form `(`-suffixed entry could not match; entries are matched as SUBSTRINGS, and the scan runs BEFORE the `cell-accessor-rename.ts` `_scrml_cs_` rename).
compiler/src/codegen/runtime-chunks.ts  — the chunk catalog + `CHUNK_DEPENDENCIES` (:384), the declarative cross-chunk dependency edge set closed over at the END of `detectRuntimeChunks`. Read this WITH emit-client.ts, never instead of it.
compiler/src/codegen/emit-server.ts  — server emission. **D-4 (S296): server import specifiers are emitted in DIST coordinate space, not source space** — `distRelativeServerSpecifier(sourceSpecifier, importerFilePath, outputBaseDir)` (exported), with `isOutsideBase` and `distServerPathOf` helpers, mirroring `api.js`'s `pathFor` exactly (SPEC §47.9.5 strips a leading `pages/` from the DIRNAME only). Falls back to a verbatim source-space specifier when `outputBaseDir` is absent or either endpoint is outside the base. **D-5 (S293): `emitReferencedModuleConstLines(fileAST, assembledBody)`** — emits the module-level `const`/`let` VALUE bindings the server bundle closes over (ADDITIVE; the client bundle is unchanged), fail-closed on any initializer whose free identifiers do not all resolve at server module scope.
compiler/src/api.js  — the pipeline spine. **D-4 (S296): the dist-keyed FORWARD index.** `distServerKeyToSource` (dist-relative `.server.js` POSIX key -> absolute source path) + `distDirOfSource`, both built through the same `stripPagesPrefix`+`pathFor` transform; `serverImportTargetSource(importerSourcePath, relServer)` reverses an emitted specifier in DIST space first, SOURCE space as the legacy fallback. **BOTH reversal sites route through it** — `checkServerImportInvariant` (the `W-SERVER-IMPORT-UNEMITTED` guard, which was blind to the very class it exists to catch because it validated in source space) and `emitValueOnlyServerJsForDanglingImports`. A forward index is required because the inverse transform is AMBIGUOUS (`models/auth.server.js` could come from `models/auth.scrml` OR `pages/models/auth.scrml`). Also this window: the `tabSpan -> span` lift in `collectErrors` (S294 — restores `:line:col` on every TABError in the build/dev path).
compiler/src/tailwind-classes.js  — the Tailwind v3 utility registry + the `W-TAILWIND-001` / `W-TAILWIND-UNRECOGNIZED-CLASS` / `E-TAILWIND-001` diagnostic surface (`findUnsupportedTailwindShapes`, `findUnrecognizedClasses`, `validateArbitraryCss`). **This window (D-3): NEW `registerOutline()`** — the whole `outline-*` family was absent, so every real `outline-*` utility false-fired `W-TAILWIND-UNRECOGNIZED-CLASS`. Registers `outline` (v3 = `outline-style: solid`, NOT a width), `outline-{dashed,dotted,double}`, `outline-none` (v3's TRANSPARENT-outline trick, deliberately NOT v4's `outline-style: none` — emitting v4 semantics would delete the forced-colors accessibility affordance), `outline-{0,1,2,4,8}`, `outline-offset-{0,1,2,4,8}`, and the full `outline-{color}-{shade}` palette loop. `outline-hidden` is deliberately NOT registered (v4-only vocabulary).
compiler/src/protect-analyzer.ts  — §14.8.9 protect-floor + the `E-PA-*` family (7 codes, this file is the sole fire site). **This window: `E-PA-002`'s message now LEADS with the `<schema>` + `scrml db-migrate` remedy** ("declare … in a `<schema>` block, then run `scrml db-migrate . --db <path>`"), demoting the old hand-written-`CREATE TABLE` advice to an "Otherwise" fallback — adopters were being taught to hand-build a schema against `bun:sqlite`. Test: `compiler/tests/unit/e-pa-002-db-migrate-remedy.test.js`.
compiler/src/schema-differ.js  — the desired-vs-actual differ + DB-authoritative DDL emitter (+389 lines this window). NEW exports: `columnConstraintDrift(desiredCol, actualCol)` (§38.6.2 rows 6/7/8 — NOT-NULL/UNIQUE/REFERENCES/DEFAULT drift on an EXISTING column, PK-aware, with a tolerant `sameDefaultText` normalizer so a driver's echoed cast never reads as permanent phantom drift) and `referencesHint(raw)` (the `E-SCHEMA-011` message's "you wrote X, the only form is Y" hint). NEW private helpers `blankLiteralBodies`, `groupBy`, `sameDefaultText`. `diffSchema` gained the **queried-table grant branch** (S292): gated on ≥1 db-authoritative table, it emits `GRANT <exercised privileges> ON <table> TO scrml_app` for each NON-db-authoritative table the project's `?{}` bodies touch — no RLS, no policy, no column narrowing, and SELECT (not CRUD) as the absent-info fallback. Also `W-SCHEMA-CONSTRAINT-TIGHTENED` / `W-SCHEMA-CONSTRAINT-DRIFT-UNAPPLIED`.
compiler/src/commands/db-migrate.js  — the `scrml db-migrate` CLI. **This window:** imports `tableRefsInSource`; `parseProjectSchema` now also returns `{queriedTables, queriedPrivileges, undeterminedSql}`; **`runPgApply`'s signature widened** to `{connectionString, desired, dryRun, allowDestructive, queriedTables, queriedPrivileges}` and threads both into `diffSchema`'s options at all three call sites; `printPlan(plan, actualTableCount, warnings = [])` now distinguishes an EMPTY plan from a WITHHELD one (`W-SCHEMA-CONSTRAINT-DRIFT-UNAPPLIED` present ⇒ prints "NOT up to date", not "up to date"); every `undeterminedSql` entry prints an explicit operator warning naming the un-scanned query.
compiler/src/runtime-template.js  — the client runtime shipped into generated apps (+218 lines this window, navigate-wave1c cross-chunk soft-nav). `_scrml_nav_missing_chunks(doc, path)` / `_scrml_nav_client_chunks(d, baseHref)` — the ordered set of client chunks the TARGET document references that the live document lacks, **keyed on the RESOLVED ABSOLUTE url on BOTH sides** (`g-nav-chunk-basename-collision-key`: a route's own script emits with NO directory component, so `pages/reports` and `pages/admin/reports` both reference `reports.client.js`; content hashing does not disambiguate them because §47.9.8 hashing is build-path only). `_scrml_nav_chunk_failed(path, token, url, reason)` emits `W-NAV-CHUNK-LOAD-FAILED` and hard-navigates; a failure arriving after a newer nav bails silently (last-nav-wins, §20.8.5). `_SCRML_NAV_CHUNK_TIMEOUT_MS` is the load budget. **`_scrml_chunk_loading` is a DEPTH COUNTER, not a boolean** — the name is kept because the emitted boot dispatch tests it for truthiness; it must count so two OVERLAPPING cross-chunk navigations do not clear the flag out from under the second chunk (which would then register `_scrml_boot` on a `DOMContentLoaded` that already fired and never fires again — correct SSR markup, completely unwired, no diagnostic). `_scrml_nav_soft_navigate_or_hard` is retired-but-retained (a test pins its presence in the runtime text); **do NOT re-wire it** — it would reinstate the cross-route hard-nav Wave-1c removed.
compiler/src/codegen/emit-event-wiring.ts  — event-handler wiring. **This window (navigate-wave1c): the BOOT DISPATCH changed shape.** Was a bare `document.addEventListener('DOMContentLoaded', function(){…})`; now an IIFE wrapping `function _scrml_boot(){…}` plus a dispatch that boots IMMEDIATELY when `_scrml_chunk_loading` is truthy (an injected route chunk, where DCL has already fired) and otherwise defers to `DOMContentLoaded` (initial load, byte-for-byte unchanged). Shared document-level listeners are idempotent-guarded at their own sites, so a re-run boot never double-registers.
compiler/src/codegen/index.ts  — the codegen dispatcher. Owns the chunk-namespace WIRING, the §40.8.2 multi-file shell composition, and the `E-DBAUTH-SQLITE` compile-time driver-resolution gate (`annotateDbScopes`). **It does NOT own the runtime-chunk gates** — those are `emit-client.ts` (see above). **This window (GH #235):** `computeDependencyClientScripts` gained a 4th `hostFilePath` param so a SHELL's dependency scripts resolve against a CHILD page's dist dir; the composed document's trailing-script strip became a repeated-group `(…)+\s*$` regex (the two single-tag strips left a third tag surviving when a page had its own cross-file dep); and the composed script set is now rebuilt as **shell deps -> shell bundle -> page deps -> page bundle**, de-duplicated by exact src via `pushScript`/`seenScriptSrc`. Ordering is the contract, not mere presence — classic `<script>` eval is sequential and each dep's `_scrml_modules[…] = {…}` footer must run before the bundle whose top-level destructure reads it.
compiler/src/codegen/emit-lift.js  — for-lift emission (+193 this window, S293). `computeItemDerivedReplay(bodyText, forceIterVars, bail)` — the shared item-derived-local REPLAY prelude for per-item effect/handler wraps (re-resolve needed ancestor iter vars outermost-first, then replay each needed item-derived local decl deps-first through the same `emitLogicNode` lowering the render path uses). `_collectDeclNodesInScope(body, out)` collects `let`/`const` decls in SOURCE order, descending into `if`/else-if blocks that share the iter-var scope but deliberately NOT into inner for-stmts (those own their own reconcile ctx). Purely additive: a binding referencing no item-derived local emits byte-identically to the prior iter-var-only re-resolve.
compiler/src/codegen/emit-each.ts  — `<each>` emission (+125 this window, S294). `pickReferencedEnclosingCtxs(refs)` / `referencesFreeIdent(blanked, name)` / `enclosingResolvePreludeLines(codeForScan, indent)` / `enclosingResolvePreludeForHandler(handlerBody)` — a nested each's inner binding that reads an OUTER loop var now re-resolves on a same-key outer reconcile. **Shadow-safe by construction:** a name bound by a NEARER ctx shadows a same-named enclosing var, so re-declaring it would be both semantically wrong and a `let` redeclaration collision.
compiler/src/codegen/emit-variant-guard.ts + emit-html.ts + binding-registry.ts  — i225 (form-control `value=` inside a `<match>`/`<engine>` arm body). `LogicBinding.directiveIsFormValue` is computed at REGISTRATION in `emit-html.ts` (where `tag` and the sibling attrs are in scope — the arm wire fn only sees the pre-lowered binding) and gates `emit-variant-guard.ts` to write the caret-safe `.value` PROPERTY (`{ const _v = expr; if (el.value !== _v) el.value = _v; }`) instead of `setAttribute("value", …)`. Mirrors the file-scope i174 `isFormControlValue` fix in `emit-bindings.ts`; falls through to `setAttribute` when a sibling `bind:value`/`bind:valueAsNumber` owns the property.

## Monorepo Note — CHANGED this window
**scrml is NO LONGER an npm workspace monorepo.** `171f5f23` (make scrml publishable) **deleted `compiler/package.json`** and **removed `"workspaces": ["compiler"]`** from the root manifest; `acorn` and `astring` were hoisted into the root `dependencies`, and `"private": true` was dropped. There is now exactly ONE package manifest in the repo. Any doc still describing `compiler/package.json` v0.2.0 or a workspace layout is stale.
