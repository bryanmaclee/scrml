## 1. `{expr}` compiles clean and renders as literal text

Source (`/tmp/verify1/t.scrml`):

```scrml
<program>

${
  <count> = 0
}

<div>
  <p>A: ${@count}</p>
  <p>B: {@count}</p>
</div>

</program>
```

`scrml compile t.scrml` → **exit 0**, no error, no warning.

Emitted `dist/t.html`:

```html
15:  <p>A: <span data-scrml-logic="_scrml_logic_1"></span></p>
16:  <p>B: {@count}</p>
```

Line 15 is a reactive binding. Line 16 is the literal string `{@count}` shipped to the user.

**Why this one matters more than its size suggests.** `{expr}` is the JSX/Svelte/Vue interpolation
form. It is the single most likely thing a developer arriving from any mainstream framework will
type, and the most likely thing an LLM will emit — every model's pretraining says `{expr}` and none
of it says `${expr}`. The failure is invisible: green compile, page renders, wrong text on screen.

A lint (`W-BRACE-LOOKS-LIKE-INTERPOLATION` or similar) on a bare `{…}` inside a markup free-text body
that contains an `@`-sigil or a known cell name would catch it with, I'd guess, near-zero false
positives. Not proposing spec surface — just flagging that the diagnostic slot appears empty.

## 2. A file without `<program>` emits its entire body verbatim

Source (`/tmp/verify2/t.scrml`) — `<program>`/`</program>` replaced with `component App {` / `}`:

```scrml
component App {

${
  <count> = 0
}

<div>Hi ${@count}</div>

}
```

`compile t.scrml` → **exit 0**, `Compiled 1 file in 44.1ms -> dist/`, and on current HEAD **zero
warnings** — not one lint fires.

Emitted `dist/t.html`:

```html
<body>
component App {

${
  <count> = 0
}

<div>Hi ${@count}</div>

}
```

The `${…}` block, the `<count> = 0` declaration, all of it — passed through as literal HTML body
text. Nothing compiled. Zero diagnostics.

**I am not claiming this is a bug.** Treating a `<program>`-less file as static-HTML passthrough may
well be intentional and specified. What looks wrong is the *silence*: a file whose body visibly
contains `${` and a `<name> =` cell declaration produces no lint at all, and the failure mode is a
whole app that compiles green and does nothing.
